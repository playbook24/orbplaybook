ORB AIDE

Bienvenue sur l'Aide ORB

Ce guide complet vous explique en détail le fonctionnement de chaque page et fonctionnalité de votre application ORB Tactical Board.

NOUVEAUTÉS : Tri Personnalisé & Tags de Séances
  • Tri Personnalisé : Vous pouvez désormais choisir l'ordre d'affichage de vos dossiers, schémas, fiches et tags dans toute l'application ! Cliquez sur l'icône située en haut à droite des pages. Une liste s'ouvrira vous permettant de glisser ou d'utiliser les flèches pour modifier l'ordre à votre guise.
  • Tags Globaux : Les icônes remplacent les boutons "Gérer les tags". Vous pouvez dorénavant créer des tags non seulement pour vos exercices, mais aussi pour vos Séances d'Entraînements, vos Fiches PDF et vos Archives.
1. Accueil (Tableau de Bord)
  • Navigation : L'accueil centralise l'accès à toutes les autres pages via des boutons principaux (Playbook, Bibliothèque, Séance, Calendrier, Effectif, Paramètres, Archives, Aide).
  • Sauvegarde Cloud : Vous y trouverez les boutons Google Drive pour sauvegarder (Envoyer) toutes vos données sur votre compte Google ou les restaurer (Charger) sur un nouvel appareil.
  • Backup Local : En bas de la page, vous pouvez créer un fichier `.json` contenant toute votre base de données locale (Exporter le Backup), ou en charger un (Importer le Backup).
2. Playbook (Dessin de Systèmes)
  • Terrain & Joueurs : Ajoutez des joueurs (Attaque/Défense) et des plots. Déplacez-les librement.
  • Dessin & Lignes : Utilisez l'outil Pinceau pour dessiner à main levée, ou créez des flèches rectilignes, courbées et des tracés de dribble via la barre d'outils.
  • Animation Automatique : Le ballon peut être assigné à un joueur. Si vous déplacez le joueur avec le ballon, ce dernier le suit.
  • Paramètres Terrain : Changez le type de terrain (Entier, Demi, FIBA, NBA) et sa couleur d'accentuation en utilisant la barre de droite.
  • Sauvegarde : Cliquez sur "Sauvegarder", choisissez vos Tags pour l'organiser, et enregistrez le système dans la Bibliothèque (ou un dossier spécifique).
3. Bibliothèque (Vos Systèmes)
  • Organisation : Retrouvez tous vos systèmes sauvegardés sous forme de cartes.
  • Dossiers : Créez des dossiers via le bouton "+" en haut et glissez-y vos systèmes pour les trier par catégorie.
  • Tags : Utilisez le bouton "Gérer les Tags" pour créer une liste globale de tags (ex: Pick&Roll, Système Cornes). Ensuite, assignez ces tags à vos systèmes et filtrez votre bibliothèque en cliquant sur les tags en haut de page.
  • Actions : Vous pouvez éditer, dupliquer, télécharger en image (.png) ou supprimer vos schémas.
4. Création de Séances d'Entraînement
  • Assemblage : Dans cette page, vous construisez des plans d'entraînement complets.
  • Ajout de Blocs : Cliquez sur "+" pour ajouter un nouvel exercice. Vous pouvez lui donner un nom, une durée et surtout y associer un ou plusieurs dessins depuis votre Bibliothèque.
  • Organisation : Réorganisez vos blocs avec les flèches Haut/Bas.
  • Exportation PDF : Une fois la séance finalisée, vous pouvez générer un fichier PDF propre (pour l'imprimer ou l'envoyer sur WhatsApp).
  • Sauvegarde & Dossiers : Les séances complètes peuvent également être enregistrées dans des dossiers dédiés pour les retrouver plus tard.
5. Effectif & Joueurs
  • Création d'Équipe : Créez vos différentes catégories (ex: U15 F, Seniors M).
  • Modale Globale : Cliquez sur le bouton "Modifier" d'une équipe pour :
    • Renommer l'équipe.
    • Lui assigner une de vos couleurs (Noir, Or, Rouge, Jaune ou libre).
    • Ajouter, supprimer ou modifier tous ses joueurs.
  • Cartes Joueurs : Les joueurs d'une équipe affichent un résumé de leur taux de présence global, aux entraînements et aux matchs.
6. Calendrier (Suivi & Présences)
  • Ajout d'Événements : Cliquez sur une date pour y ajouter un entraînement ou un match.
  • Liaison Équipes & Séances : Vous pouvez lier un ou plusieurs effectifs à l'événement, et y attacher un plan d'entraînement sauvegardé.
  • Faire l'Appel : Dans le détail de l'événement, vous voyez la liste des joueurs des équipes liées. Vous pouvez noter leur présence (Présent, Absent, ou Blessé). L'option "Blessé" ne pénalise pas le taux de présence global du joueur.
  • Scores de Match : S'il s'agit d'un match, vous pouvez entrer votre score et celui de l'adversaire.
7. Archives & Tri
  • Archivage d'Équipe : Dans la section Effectif, vous pouvez "Archiver" une équipe (par exemple à la fin d'une saison) pour la cacher du menu principal sans perdre ses données.
  • Gestion des Tags d'Archives : Cliquez sur "Gérer les Tags" pour créer des dossiers logiques (ex: Saison 2023).
  • Assignation : Cliquez sur une équipe archivée pour consulter son effectif, puis cliquez sur "Assigner des Tags" pour l'associer à l'un de vos filtres.
  • Désarchivage : Vous pouvez restaurer l'équipe à tout moment pour qu'elle réapparaisse dans l'Effectif actif.
8. Générateur de Fiches & PDF Studio
  • Studio PDF : Vous permet de créer rapidement des "Fiches Exercices" au format PDF, comprenant un nom, un dessin, un but, et des consignes.
  • Organisation : Comme pour les Playbooks et les Séances, les fiches peuvent être organisées dans des dossiers propres à ce module.
9. Paramètres & Personnalisation
  • Thème de l'Application : Basculez entre le thème Sombre (par défaut) et le thème Clair pour une meilleure visibilité en extérieur.
  • Identité Visuelle : Basculez entre le mode "ORB" (Noir et Or) et le mode "CRAB" (Bordeaux et Jaune). Cette option modifie les couleurs de toute l'interface ainsi que les tracés par défaut de votre terrain.
10. Synchronisation Cloud (Sécurité)
  • L'application ORB est conçue pour être la plus rapide possible en fonctionnant nativement hors-ligne (les données sont stockées sur votre appareil).
  • Pour protéger vos données ou les partager entre votre téléphone, tablette et PC, connectez votre Google Drive (depuis l'Accueil ou les Paramètres).
  • La sauvegarde est automatique en tâche de fond. Si vous changez d'appareil, connectez votre Drive et cliquez sur "↓ Charger" pour tout récupérer.
